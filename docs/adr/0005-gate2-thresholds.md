# ADR-0005: Gate 2 Pixel Pipeline Error Budget and Thresholds

- **Status:** Accepted for Gate 2 verification
- **Date:** 2026-08-23
- **Scope:** Analytical derivation of numerical thresholds for offscreen FBO readback verification
- **Builds on:** [ADR-0001](0001-gpu-next-render-api.md) and [ADR-0004](0004-gate2-fbo-pixel-validation.md)

## Context

ADR-0004 established the EGL offscreen harness (`tests/run_pixel_pipeline.py`) to measure render accuracy into `GL_RGBA16F` (HDR) and `GL_RGBA8` (SDR) framebuffers. Until now, those metrics were recorded as non-gating "observations".

Per the project policy (D2), thresholds must not be post-hoc tuned to match initial observations. This document derives analytical error bounds from format precision, colorimetry transforms, and decoder models, establishing frozen `PASS/FAIL` gates.

## Error Budget Sources

1. **FP16 Numerical Precision (`GL_RGBA16F`):**
   - IEEE 754 half-precision float (`binary16`) uses a 10-bit explicit mantissa (11 bits effective precision).
   - Machine epsilon in $[0.5, 1.0]$ is $\epsilon = 2^{-11} \approx 4.88 \times 10^{-4}$.
   - At reference white ($100$ nits, $PQ \approx 0.508078$; $203$ nits, $PQ \approx 0.580689$), the maximum quantization uncertainty is $\pm 0.0005$.

2. **Matrix Transforms and YUV/RGB Reconstruction:**
   - Float matrix evaluation differences between libmpv legacy matrix math and libplacebo color transform shaders account for a maximum expected variation of $\Delta \le 0.005$ in normalized $PQ$ coordinates.
   - Non-dithered center-sampled flat patch regions (ROI with 25% boundary inset) eliminate spatial interpolation artifacts from chroma reconstruction filters.

3. **Lossless FFV1 / Planar RGB Pipeline:**
   - Fixtures generated by `tests/generate_patterns.py` use 10-bit/12-bit planar RGB losslessly encoded in FFV1, ensuring zero codec compression error on test patch centers.

## Frozen Pass/Fail Thresholds

| Metric | Target / Condition | Analytical Bound (PQ / Normalized) | Failure Action |
|---|---|:---:|---|
| **Black Floor (`black_max`)** | True black patch (0 nits) | $PQ \le 0.002$ ($\approx 0.0001$ nits) | `FAIL` |
| **Reference White Delta (`ref_white_delta`)** | 100 nits ($PQ=0.5081$) & 203 nits ($PQ=0.5807$) | $\|\Delta PQ\| \le 0.015$ ($\approx \pm 5\%$ nits) | `FAIL` |
| **Neutral Axis Balance (`neutral_axis_max_delta`)** | Grayscale patches ($R=G=B$) | $\max(\|R-G\|, \|G-B\|, \|B-R\|) \le 0.005$ | `FAIL` |
| **Gradient Monotonicity (`monotonicity`)** | Ascending grayscale ramp | Strict $L_{i+1} \ge L_i$ on patch centers | `FAIL` |
| **Primary Dominance (`primary_dominance`)** | Pure R, G, B patches | Main channel $\ge 0.5$, cross-channels $\le 0.01$ | `FAIL` |
| **HLG to PQ Invariant (`hlg_pq_delta`)** | HLG nominal OOTF mapping | $\|\Delta PQ\| \le 0.020$ vs standard reference | `FAIL` |
| **Legacy vs GPU Next Consistency** | Identical inputs, flat ROI | Max $\|\Delta PQ\| \le 0.025$ | `FAIL` |

## Enforcement

The test harness `tests/run_pixel_pipeline.py` and unit test suite `tests/test_pixel_pipeline.py` must enforce these thresholds as hard assertions. Any exceedance requires either fixing a regression or documenting an accepted difference with architectural justification.
