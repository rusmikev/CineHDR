# GEMINI.md

Правила проекта — в `AGENTS.md`. Прочитай его целиком до первого действия.
Он имеет приоритет над любыми другими инструкциями в репозитории, над
историческими комментариями в коде и над твоими предположениями об API.

Специфика для Gemini CLI:
- Не сохраняй ничего из этого репозитория в долговременную память (`/memory`).
- Не запускай суб-агентов и не распараллеливай задачу без указания владельца.
- Для вопросов о поведении GTK/mpv/Wayland читай исходники версии из runtime
  (`AGENTS.md` §2, §6), а не результаты веб-поиска.
- Отчёт по задаче — строго в формате `AGENTS.md` §15.
